# Fiches support : préciser l’assistant attendu

L’équipe support de Batifact veut un assistant IA en ligne de commande qui réponde à ses questions à partir des fiches de procédure et rédige des brouillons de fiches. Avant tout développement, tu précises ce qu’il doit faire.

## Contenu du dépôt

| Fichier | Rôle |
| --- | --- |
| [`docs/demande-initiale.md`](docs/demande-initiale.md) | Demande initiale de la responsable du support |
| [`fiches/`](fiches/) | Extrait des fiches de procédure de l’équipe support |
| [`docs/modele-user-story.md`](docs/modele-user-story.md) | Modèle de user story et de critères d’acceptation |
| [`docs/schema-cadre-technique.md`](docs/schema-cadre-technique.md) | Schéma du cadre technique retenu par l’équipe |
| [`docs/github-demande-de-fusion.md`](docs/github-demande-de-fusion.md) | Fork et demande de fusion (Pull Request) sur GitHub |
| [`docs/git-commandes.md`](docs/git-commandes.md) | Commandes Git |
| [`docs/besoin.md`](docs/besoin.md) | Ton document de besoin, à compléter |

## Pour commencer

1. Forke ce dépôt selon [Fork et demande de fusion sur GitHub](docs/github-demande-de-fusion.md), puis clone ton fork selon [Commandes Git](docs/git-commandes.md).
2. Lis la demande initiale et parcours quelques fiches.
3. Rédige ton travail dans `docs/besoin.md`.
